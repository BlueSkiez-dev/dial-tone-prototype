# Dial Tone — design prototype

Visual-direction prototype for **Dial Tone**, a messenger that sends text as modem sound over any audio channel (room, phone call, voice note). Entry for Kiroween 2026.

**Live:** https://blueskiez-dev.github.io/dial-tone-prototype/

This is a design reference ("Ghost in the Line"), made before the build as pre-build research. The real app is built in Kiro in [BlueSkiez-dev/dial-tone](https://github.com/BlueSkiez-dev/dial-tone).

- Flip the power switch, allow the microphone, and send between two phones.
- No second phone? Open **Prototype controls** to play a real transmission through the real decoder.

Data-over-sound by [ggwave](https://github.com/ggerganov/ggwave) (MIT, see `vendor/GGWAVE-LICENSE.txt`).
